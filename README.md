# Daily-Habit-Tracker
A Flutter-based daily habit tracking application developed using Dart as part of a team project. The app allows users to create, customize, edit, and track daily habits, set reminders, manage completed and archived habits, and monitor their progress through streaks, completion rates, statistics, and interactive charts. Developed using Agile/Scrum methodology across multiple sprints.
